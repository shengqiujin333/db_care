# 关键器件选型类别（CS-001）

状态：硬件方案设计产物（器件**类别与约束**；具体料号在 `component_selection` 细化，schematic 阶段定稿）
版本：1.0
对象：传感器新增 F1 霍尔、F2 光敏接收前端
关联：artifacts/hardware_solution.md（HW-001）

> 本能力给出器件类别与电气约束，满足 IC-001 §8 与 HW-001 的功能块需求；不锁定单一料号，避免供应链单一化。

## 1. F1 霍尔开关

| 属性 | 要求 |
|---|---|
| 类别 | 单极霍尔开关 IC（数字输出） |
| 供电 | 2.2–5.5V（3.0V CR2032 直接供） |
| 输出 | 开漏或推挽数字电平，兼容 CW32 GPIO |
| 静态电流 | µA 级（<10 µA 优先），保证待机暗电流预算 |
| 触发 | 磁铁接近产生有效沿；磁通阈值覆盖门磁应用 |
| 去耦 | 配小值去耦电容 |
| 代表类别 | A3144E 类单极霍尔开关 / AH180 类微功耗霍尔开关（仅类别参考，非锁定） |

## 2. F2 光敏接收前端

| 器件 | 要求 |
|---|---|
| 感光 | 光敏三极管（光电晶体管），可见光/白光 LED 敏感，暗电流极小 |
| 负载电阻 | 按 3.0V 供电、25 Hz 带宽、<2 mA 持续电流选值 |
| 输出 | 光→数字电平（暗=低、受光=高，方向可配），接施密特输入 |
| 供电开关 | 低压 P-MOS 高边 或 N-MOS 低边，GPIO 驱动，低导通压降/低泄漏 |
| 去耦 | F2 VCC 节点加去耦电容，抑制 30 s 上电瞬间 |

## 3. 电源/去耦

- 无新增电源管理 IC；CR2032 直供 3V（现状）。
- 若 Hall 静态电流偏高（>5 µA），schematic 阶段为 Hall 复用同一类型 GPIO 开关关断。

## 4. 选型约束汇总（交接 schematic）

- 全部器件 3.0V 工作、低功耗、尺寸适配 CR2032 纽扣板小面积。
- 光敏前端持续电流 <2 mA；待机暗电流目标 <10 µA。
- 器件封装与现有板工艺兼容（沿用现有焊装方式）。
