3. UART1 调试通道在 COM43/9600 8N1 上真实输出完整 `S` 行（81 B 含 CRLF，≤96 B），字段可解析；采样节拍 `k` 按 3 的倍数推进。
4. 光照通路**没有**获得可用的“有光/无光”分离证据：本次两笔实测 `a=3914`、`a=3915`（近满量程、暗端），而 readme 描述“当前的情况是有光的”。按 12 bit ADC 与 `dark = valid && 3*mean >= C_dark` 的算术，只要 `C_dark ≤ 4095`，任何 `mean ≥ 1365` 都会被判为暗；当前读数对任何 12 bit `C_dark` 都恒为暗。若该读数确实代表“有光”，则 1/3 判据无法满足需求；若传感器实际处于遮光/未装/开路状态，则同一读数不能证明光照通路正常。二者尚未区分，属于影响方案的关键原因。

因此本报告只把驱动、通信、启动/打印和节拍列为“可行”，把光照判据列为“未证实/阻塞”，不把任何未执行项写成通过。

### 3.2 UART1/COM43 真实输出

原始两行（逐字节，含 CRLF）：

```
S k=1140 p=252 H=1 V=0 o=8 n=3913 x=3917 a=3914 D=0 t=252 h=326 q=1 r=0 s=0 y=0
S k=1146 p=250 H=1 V=0 o=8 n=3913 x=3918 a=3915 D=0 t=249 h=329 q=1 r=0 s=0 y=0
```

字段含义（来自当前 `debug_trace.h`/`debug_trace.c`，非本轮新造）：`k`=RTC 累计分钟节拍；`p/H`=判定所用前值与是否有前值；`V`=光照 valid（未标定门限）；`o`=成功 ADC 样本数；`n/x/a`=光照最小/最大/均值 ADC 码；`D`=dark；`t/h`=温度/湿度 ×10；`q`=温湿度采样有效；`r`=条件上报判定；`s`=433 发送结果；`y`=重试。

判读：

1. 两行均为 81 B（含 CRLF）≤96 B，ASCII、CRLF 完整、无杂散字节；采样间期无输出。
2. 两行 `q=1`、`t=252/249`（25.2/24.9 ℃）、`h=326/329`（32.6/32.9 %RH），在有效域内；GXHT40 采集路径在真实目标上工作。
3. 两行 `V=0 D=0 o=8`：8/8 光照 ADC 转换成功，但因 `LIGHT_DARK_CALIBRATED=0`，`valid` 恒假、`D` 恒假。**这只证明未标定门禁在工作，不证明光照判据正确**。
4. `k` 从 1140 到 1146，跨两个捕获窗口（中间 06:36:12–06:39:51 未采集）；缺失的 `k=1143` 落在窗口间隙，步长仍为 3 的倍数。结合 EV-026 的 15 条连续 `S`（k=0…57，全部 3 的倍数）与 EV-028/029 的 `p` 链，3 分钟节拍方向成立；本轮没有用单个窗口伪装成连续 180 s 实测。
5. `p(k=1146)=250`，与上一周期（k=1143，未捕获）的 `t=250` 自洽；不能由本窗口单独证明完整 `p` 链，故只作一致性观察，完整链引用 EV-028。

### 3.3 GXHT40 I²C 被动采集（当前窗口）

- 仪器/入口：`fx2lafw:conn=2.32`，D0=SCL、D1=SDA、共地（按登记配置）；4 MS/s，20,000,000 样点，5.0 s；触发 `D1=f`（SDA 下降沿）。原始 `raw_i2c_capture.sr` md5 `9e77da5530e16e0f7d41f5b1d148559a`。
- 离线解码（`i2c:scl=D0:sda=D1`）：

```
Start
Address write: 44   ACK
Data write: FD      ACK
Stop
Start
Address read: 44    ACK
Data read: 66 66 93 4F 25 E2   (last byte NACK)
Stop
```

- 独立复算（不引用固件常量）：
  - 温度字 `0x6666=26214`，CRC-8(poly 0x31, init 0xFF) 计算 `0x93` = 收到 `0x93` ✅；`T=-450+round(1750*26214/65536)=250`（25.0 ℃）。
  - 湿度字 `0x4F25=20261`，CRC-8 计算 `0xE2` = 收到 `0xE2` ✅；`RH=-60+round(1250*20261/65536)=326`（32.6 %RH）。
  - 与同一时段 `S` 行 `t=252 h=326` 一致（温度差 0.2 ℃ 属相邻采样量化/时点差，未伪造成同一笔）。
- 时序（样点号 / 4 MS/s，名义值，不是主机时间戳）：
  - 写事务 START→STOP `12.049 ms`；读事务 `40.157 ms`；命令 STOP→读 START `32.526 ms`。
  - SCL 位周期中位数 `2457` 样点 = `614.25 µs`（≈1.63 kHz），与 EV-026 的 614.5 µs 同量级。
- 结论：**GXHT40 驱动/通信/CRC/换算在当前目标上可行**。数字采样只证明逻辑电平和采样分辨率内的时序，不证明模拟幅度/上升沿形状；单个 5 s 窗口不能外推长期稳定性。
- 与历史差异：EV-028/029 的 `2.27` 不可达；本次登记值 `2.32` **首次在本轮可达**，因此更新的是“当前窗口仪器可用”，不是“2.27 已修好”。

### 3.4 光照通路与 1/3 判据（阻塞项）

#### 3.4.1 硬件与代码事实

- 网表/BOM：PB05（`LIGTHT_POWER`）—R3 `5M`—`LIGHT_ADC`（PB04/AIN11）—J4（`GL4539_2` 光敏）—GND；BOM 中无第二处分压/上拉。PB04 只作 AIN11 模拟输入，PB05 只作光照供电输出。
- 极性：有光 → 光敏阻值小 → 分压点低 → ADC 码小；完全无光 → 阻值大 → ADC 码大（接近满量程）。
- 判据：`dark = valid && (3*mean_adc_code >= C_dark)`；`valid = adc_ok && LIGHT_DARK_CALIBRATED`；当前 `C_dark=0`、`CALIBRATED=0`，所以 `V=0/D=0`。

#### 3.4.3 1/3 判据的算术敏感性（计算，不是实测）

12 bit ADC 最大 `C_dark=4095`；`dark` 条件等价于 `mean >= ceil(C_dark/3)`：

| 当前 mean | 不变暗所需 `C_dark` | 12 bit 内是否可能 | 结论 |
|---|---|---|---|
| 3914 | `> 11742` | **否** | 对任何 12 bit `C_dark` 都判暗 |
| 3915 | `> 11745` | **否** | 对任何 12 bit `C_dark` 都判暗 |

进一步：只要 `mean >= 1365`，对 `C_dark=4095` 已判暗；`mean >= 1167` 对 `C_dark=3500` 判暗。当前读数远高于这些阈值。

判读：

- **若用户所说“当前有光”确实指光敏器件受光**，那么 1/3（ADC 码域）判据在数学上无法把当前状态判为“有光”；这不是标定精度问题，而是判据/分压/安装位置的可分性问题。不得通过反复改固件或把 `C_dark` 设成不可能的值来“修好”。
- **若传感器实际处于遮光/暗处**，当前高码是正常的暗态；此时仍需一次“强光照射”证明低码端存在，才能证明分离可用。
- 当前 `CALIBRATED=0` 使设备不会误报；这不能作为“光照通路正常”的证据，反而是“未验收”的门禁。

#### 3.4.4 竞争假设（均未排除）

| 假设 | 支持现象 | 需要的判别 |
|---|---|---|
| H-L1 光敏实际处于遮光/暗处（用户“有光”指房间而非器件） | 读数稳定近满量程；历史夜间也高 | 强光照射下 `S` 的 `a` 是否显著下降 |
| H-L2 J4/GL4539 未装或开路，节点被 R3 拉高 | 近满量程、对时间不敏感、白天不降 | 目视/BOM 核对 J4；强光无变化则支持 |
| H-L3 R3 不是 5 M 或分压焊接异常 | 近满量程 | 目视/万用表测 R3 与节点电压（当前无仪器授权） |
| H-L4 PB04/AIN11 通道或 PB05 驱动异常 | 代码静态正确但实板无响应 | 上电 `IOTEST/IOSIG/BUS` + 节点电压；或换板对照 |
| H-L5 ADC 参考/采样时间/电源异常 | VDD 未测；样本 8/8 成功 | 读取 `VDD` 行；示波器/万用表测 PB05/PB04（当前无仪器） |

**没有实验把任一假设排除；因此不能把现象归为“外部装配问题”后放行。**

### 3.5 上电五行与 UART1 初始化边界

- 本轮串口窗口只得到 `S` 行，没有 `BOOT/VDD/IOTEST/IOSIG/BUS`。原因：本能力没有 `mdk_flash`/复位入口，串口只能在板子已运行时打开；无法在端口打开前制造复位。
- `S` 行的存在证明 UART1 已在 9600 8N1 上初始化并打印；但“上电横幅五行 + uid”未取得，不能标通过，也不能用后续 `S` 替代。
- 复用 EV-028：其在 `Application running` 后约 73 ms 才打开串口，仅得 `BUS idle=3 scl=1 sda=1 ack=44`，`BOOT/VDD/IOTEST/IOSIG` 已输出完毕。该窗口限制仍存在；需要“先开采集、窗口内复位”的编排（测试/调试责任方），不是固件代码缺陷。

## 5. 已证实 / 已否定 / 仍未知

### 5.1 已证实（本轮原始证据）

- 当前源码可 `rebuild`（0 Error/1 既有 warning），产物与 EV-028 镜像同 md5。
- COM43/9600 8N1 上 UART1 打印 `S` 行，格式/行长/CRLF 正确。

- 采样 `k` 以 3 的倍数推进；与历史连续证据一致。
- 当前登记 `fx2lafw:conn=2.32` 在本轮可达；被动采集/离线解码可用。

### 5.2 已否定 / 与预期不符

- “当前光照读数可以作为有光基准”：不成立。`a=3914/3915` 位于暗端，且对任何 12 bit `C_dark` 都判暗；不能据此回填 `C_dark` 或宣称 1/3 判据可用。
- “白天更亮 → ADC 更低”在本轮不成立（白天读数反而最高）；原因未区分，不能归为单一外部因素。
- “`V=0 D=0` 说明光照通路正常”：不成立，只说明未标定门禁生效。

## 6. 最小下一步实验（按优先级）

### E1（阻塞，必须先做）：受控“强光/全遮光”实板判别

目的：区分 H-L1（实际暗）与 H-L2/H-L3/H-L4/H-L5（未装/开路/分压/通道/前端），并判断 1/3 判据是否有可用分离。

步骤（有界，单次 ≤4 分钟，保持状态后采集）：

1. **目视核对**：确认 J4（GL4539 光敏）实际装配、R3 为 5 M、PB05—R3—PB04—J4—GND 与网表一致；记录板件标识/照片。若未装或开路，直接停在这里，交硬件责任方，不用固件“修”。
2. **强光窗口**：用手机手电/台灯近距离照射光敏器件，保持 ≥4 分钟；在此期间执行 `serial_capture`（COM43/9600，200–240 s），记录至少 1 条 `S` 的 `a/n/x`。
   - 预期（若通路正常）：`a` 显著低于 1365，最好接近 0。
   - 若 `a` 仍 ≥1365 或几乎不变：支持 H-L2/H-L3/H-L4/H-L5；进入第 4 步。
3. **全遮光窗口**：用不透光物完全遮住光敏器件及受光路径，保持 ≥4 分钟；`serial_capture` 记录 `a/n/x` 分布。
   - 预期：`a` 明显高于强光值，接近 `C_dark`；记录 min/max/mean，作为 `C_dark` 候选（不回填未测值）。
   - 若强光低码 + 全遮光高码且分离足够：可进入 `C_dark` 回填与 `CALIBRATED=1` 的条件；仍须在重建后用同一板件复测明/暗/无效三态。
4. **若强光无响应**：不要再反复改固件；先核对 J4/R3/焊点，必要时用万用表测 PB05 高电平、PB04 节点电压、R3 阻值（当前环境未登记万用表/示波器，需补配置/授权），或用已知良板对照。若确认传感器正常但“有光”读数仍 ≥1365，则 1/3（ADC 码域）判据与需求冲突，交需求方/硬件方决定，不得静默改判据。

成功判据：同一板件、同一供电/建立时间/8 样本平均下，强光 `a` 与全遮光 `a` 有明确分离，且强光侧低于 `ceil(C_dark/3)`；否则不签认 R2/R4/R7。

### E2（诊断补全）：上电五行 + uid

在串口已打开的前提下复位/上电（需要 `mdk_flash` 或人工复位编排；本能力无此入口）。目标：取得 `BOOT/VDD/IOTEST/IOSIG/BUS` 与 uid，核对镜像/供电/I²C 空闲电平/0x44 ACK。不得用后续 `S` 行替代；不得为取日志反复改固件。

### E3（测试阶段）：真实触发与跨链路

E1 通过并回填 `C_dark` 后：全遮光 + 局部升温使 `cur-prev > 0.9 ℃`，观察 `r=1`、`P` 行与 `s=1`；再在网关/手机侧核对同一笔 ID/温湿度/时间语义。另测严格 35.0 ℃ 边界（恰好 35.0 不经超温分支）与首样本无前值。此阶段属测试/联调，不在本能力执行。

### E4（硬件测试）：CR2032 供电/功耗

测采样峰值、深睡电流、UART/射频瞬态；本轮未配置相应仪器，记为未执行，不作为固件代码通过依据。
