# 硬件接口定义（HWI-001）

状态：硬件方案设计产物
版本：1.0
对象：传感器新增 F1 霍尔、F2 光敏接收与 CW32L010 之间的硬件接口
关联：artifacts/hardware_solution.md（HW-001）、artifacts/interface_contract.md（IC-001）

## 1. 接口概览

```text
Hall IC  ──> [Hall_DOUT]  ──> CW32 数字输入（中断唤醒）
                                 │
CR2032 ─> GPIO 开关 ─> F2 VCC ─> 光敏三极管 + Rload ─> [OPT_IN] ─> CW32 数字输入（采样）
```

| 信号 | 方向 | 类型 | 说明 |
|---|---|---|---|
| `Hall_DOUT` | Hall IC → MCU | 数字输入（开漏/推挽） | 磁铁接近有效电平；外部中断唤醒 |
| `F2_PWR_EN` | MCU → 功率开关 | GPIO 输出 | 高/低电平使能 F2 前端供电；默认断 |
| `OPT_IN` | 光敏前端 → MCU | 数字输入（施密特） | 采样 OOK/Manchester 亮灭电平 |

## 2. F1 Hall 数字输入接口

- 电平兼容：Hall 输出高/低电平须与 CW32L010 GPIO（3.0V 供电）匹配。
- 触发：磁铁接近产生有效沿 → MCU 外部中断唤醒深睡 → 授权 30 s 配置窗口（IC-001 §3.1）。
- 常态：低功耗，µA 级静态；方向（上拉/下拉、高/低有效）由所选 Hall 器件输出结构决定。

## 3. F2 光敏前端可关断电源接口

- `F2_PWR_EN` 控制光敏前端 VCC 功率开关；默认断开（暗电流≈0）。
- 仅 F1 触发后 30 s 窗口内闭合；超时/成功提交/连续 3 帧失败即断开（IC-001 §3.1）。
- 开关类型：P-MOS 高边或 N-MOS 低边，3V 逻辑驱动，低导通压降、低泄漏。

## 4. F2 光敏数字采样接口

- `OPT_IN`：光敏三极管经负载电阻形成的数字电平。
- 采样由 MCU 软件定时完成（Manchester 40 ms/bit，25 Hz 采样率足够）。
- 数据格式与解码由固件实现（IC-001 §3），硬件只保证电平干净、带宽充足。

## 5. 引脚候选分配（schematic 阶段核定）

| 信号 | 建议脚 | 属性 |
|---|---|---|
| `Hall_DOUT` | PB4（候选） | 输入 + 中断 |
| `OPT_IN` | PA2 或 PB5（候选） | 输入（施密特） |
| `F2_PWR_EN` | PB6（候选） | 输出 |

> 引脚为候选，schematic_design 按 CW32L010 实际能力核定，本接口不锁定硬编码。
