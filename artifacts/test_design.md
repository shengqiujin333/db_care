## 2. 测试范围与适用性

### 2.1 覆盖的产品行为

| 编号 | 行为（来源） |
|---|---|
| B1 | GXHT40 温湿度采集：地址探测（0x44/0x45）、`0xFD` 高重复率测量、6 字节读取、温度/湿度 CRC-8 校验、x10 整数换算（readme 1；FD-002 §3/§6） |
| B2 | 光照判据：PB05 供电 → 稳定等待 → PB04/AIN11 多次采样取均值 → 阈值 + 滞回得 DARK/LIT；采样后 PB05 = 低（readme 2；FD-002 §2.3/§6.3） |
| B3 | 3 分钟采样节拍：RTC 1 分钟中断累计 3 次触发一次采样；单周期内只测一次（readme 3；FD-002 §5） |
| B4 | 条件上报：`(prev−cur > 0.9 ℃) 且 DARK` 或 `cur > 35.0 ℃` 才发 433（readme 4；IC-002 §2；FD-002 §6.4） |
| B5 | 失败不伪造：I²C 失败/CRC 错按上限有界重试；整周期失败不上报、不更新前一有效温度、不构造 0 值（FD-002 §10） |
| B6 | 空口与 BLE 布局不变：433 明文 10 B `uid|temp_LE|hum_LE|crc16_LE` + Feistel；BLE 每设备 8 B `id|hum_BE|temp_BE`；网关不二次门控（IC-002 §3/§4；FD-002 §8/§9） |
| B7 | 旧通路退役且不再争用 PB04/PB05/PB06：无 hall EXTI、无 OPTCFG、无 params NVM 写、无 history 历史环（FD-002 §3.3；FWR-111） |
| B8 | 低功耗：非采样期深睡、GXHT40 待机、分压无电流、调试 UART 关闭、433 有界（FWR-106；RTA-002 §3.3） |

### 2.2 回归范围（改动相邻的既有功能）

- 既有 CRC16-CCITT-FALSE 与 10 B Feistel 加解密、`encode_frame10` 字段顺序与字节序；
- 网关 `decode_frame10` 解析与 BLE 记录顺序、Android `parsePlainFrame`（`u16be@4`/`s16be@6`）读取正确；
- 传感器既有唤醒源（RTC）、深睡入口、UM2005C 驱动与 `app_um2005C_send_data_timeout` 有界超时；
- 传感器 ID（空口 4 B）与改动前一致、稳定（Android 依赖它归因）。

## 3. 测试层次与总体策略

| 层 | 名称 | 环境 | 目的 |
|---|---|---|---|
| L0 | 宿主机纯逻辑 | 本机 gcc | 判定/换算/CRC 的确定性与边界，回归最快 |
| L0i | 宿主机空口互操作 | 本机 gcc（传感器 encoder + 网关 decoder） | 不依赖硬件的字段顺序/字节序/加密回归 |
| L1 | 构建与静态核查 | 本机 + MDK/IAR 工程文件 | 可构建、资源达标、退役符号消失、无浮点 |
| L2 | 单板功能与协议 | 传感器板 + SWD + 逻辑分析仪 + 串口 | I²C 时序、光照通路、节拍、休眠 |
| L3 | 系统联测 | 传感器 + 网关 + Android + 433 通路 | 条件上报、边界矩阵、端到端数据正确 |
| L4 | 功耗 | 电流表/SMU + CR2032 | 深睡/单周期/发射能量与预算核对 |

原则：先 L0/L0i/L1，再 L2，再 L3/L4；L3 的每条用例都必须同时留存「手机侧结果 + 串口/网关日志 + 波形/电流」中的至少两类独立证据，禁止单点证据定罪。

### 4.4 传感器 I²C 与 GXHT40 驱动（板上 · 用例组 T-L2）

| 编号 | 行为 | 前置/资源 | 方法 | 证据 | 判定 |
|---|---|---|---|---|---|
| T-L2-01 | 总线物理与地址探测 | 传感器板上电（3.0 V 台架或 CR2032）、逻辑分析仪接 PA03/PA04，上拉 4.7 kΩ 到 BAT | 抓取一个采样周期的完整 I²C 事务：START → 地址字节（写 `0x88` 或 `0x8A`）→ 命令 `0xFD` → STOP →（等待）→ START → 读地址（`0x89`/`0x8B`）→ 6 字节 → NACK → STOP | 逻辑分析仪波形/解码文本 + 时间戳 | 地址字节与器件实际变体一致（0x44→0x88/0x89，0x45→0x8A/0x8B）；SDA/SCL 空闲被外部上拉为高；每个字节后 ACK 存在 |
| T-L2-02 | tMEAS 等待下界 | 同上 | 量测「`0xFD` 的 STOP 沿」到「读地址第一个 SCL 上升沿」的时间 | 波形时间差 | ≥ 8.3 ms（高重复率 max，VDD 低至 1.6 V 的余量按 FD-002 §11.3 取 10 ms 更佳）；**若读到 NACK 后立即重读，重读间隔 ≥ 1 ms 且总重试 ≤ 上限** |
| T-L2-03 | 连续读时序正确 | 同上 | 复核 6 字节读取：前 5 字节主机 ACK、第 6 字节主机 NACK，随后 STOP；顺序为 `T_MSB,T_LSB,T_CRC,RH_MSB,RH_LSB,RH_CRC` | 波形 + 解码字节 | 字节顺序与手册 §7.2 一致（温度在前）；无 clock stretching 依赖 |
| T-L2-04 | 测量值与参考一致 | 可控温箱/冰水浴 + 参考温湿度计 | 在至少 3 个温度点（例：≈5 ℃、≈25 ℃、≈40 ℃）与 2 个湿度点稳定后，比对上报值（经 §4.7 端到端或钩子读出）与参考值 | 参考仪器读数 + 传感器记录（含时间） | 温度偏差在参考仪器与 GXHT40 手册精度合计范围内；湿度同法；**偏差超范围必须记录为缺陷，不得自行放宽** |
| T-L2-05 | 负温符号 | 冰箱/冷箱 ≈ -10 ℃ | 冷透后触发一次上报（用超温分支或下降分支，见 §4.7），在网关/Android 侧读温度 | 端到端三方证据 | 读数为负且大小正确；BLE `s16be@6` 解释不出现 6 万级大数 |
| T-L2-06 | CRC 错误路径 | 逻辑分析仪 + 故障注入（短接/断开 SDA 或 SCL 使其读回全 1/全 0，或引入 I²C 从机模拟器） | 在连续若干周期注入错误，观察是否重发 `0xFD` 重新测量、重试次数是否有界、周期结束后是否恢复 | 波形 + 电流/行为 | 每次 CRC 错丢弃整帧并重测；重试不超过配置上限；用尽后该周期结束、不挂死 |
| T-L2-07 | 总线被拉低卡死恢复 | SDA 短接 GND 一段时间后释放 | 释放后观察下一周期是否恢复通信；观察电流是否被限 | 波形 + 电流 | `sf_i2c` ACK 超时路径发出 STOP 并返回失败；后续周期可恢复；无无限等待（无持续 mA 级电流） |
| T-L2-08 | 无器件（未焊接/未上电） | 传感器 GXHT40 取下 | 观察一个完整采样周期的行为 | 波形 + 空口（应无发射）+ 电流 | 失败路径：不上报、不构造 0 值；周期有界结束并回到深睡 |

|---|---|---|---|---|---|
| T-L3-01 | PB05 供电与空闲低 | 逻辑分析仪/示波器接 PB05；可调光照 | 观察一个采样周期：PB05 在光照采样期间为高、采样结束后回到低；非采样期保持低（深睡期间用示波器长时基确认） | 波形 + 时间标注 | 采样后 PB05 = 低；非采样期无高电平；PB05 高电平期间与被测分压电流一致 |

### 4.7 条件上报判定（联测 · 用例组 T-L5，空口边界矩阵，核心）

方法：用可控温度激励（恒温箱/热风/冰袋对传感器头部）建立「前一有效温度」，再用改变温度与光照条件构造下述各情形；每次只改变一个变量，观测 433 空中是否出现新帧（433 接收机或网关日志），并记录该帧解出的 `temp/hum/id`。内侧判定可用「观测钩子报告 report 值」替代「空气中是否有帧」，但至少一次必须以真实空中帧验证。

| 编号 | 场景 | 期望（FD-002 §6.4 / FWR-104） | 判定要点 |
|---|---|---|---|
| T-L5-01 | 温度下降 1.1 ℃（`prev−cur=11`）且 DARK | 上报一次 | 帧内容 = 本次温湿度；之后若无新变化，后续周期不再重复上报 |
| T-L5-02 | 温度下降 **恰好 0.9 ℃**（差 9）且 DARK | **不上报**（IC-002 严格解释） | 记录为「0.9 含等于」未决项的双分支证据（§7）；不得因未决而判缺陷 |
| T-L5-03 | 温度下降 >0.9 ℃ 但 LIT（有光） | 不上报 | 光照条件为必要条件 |
| T-L5-04 | 温度 **恰好 35.0 ℃**（`cur=350`） | 不上报 | 严格超过 |
| T-L5-05 | 温度 35.1 ℃（`cur=351`）且任意光照 | 上报一次 | 超温分支不受光照与前值限制 |
| T-L5-06 | 无前一有效温度（冷启动/复位后）且 `cur=200` | 不上报（**不强制上报首样本**） | 复位或上电后首个周期无帧；与 FWR-108 一致 |
| T-L5-07 | 无前一有效温度且 `cur=351` | 上报 | 超温分支独立成立 |
| T-L5-08 | 前值存在、温湿度稳定无变化 | 不上报（**无周期保活**） | 连续 ≥3 个周期无帧；证明「3 分钟是采样周期而非上报周期」 |
| T-L5-09 | 上报成功后同一条件持续 | 不重复上报 | 上报即清除待上报状态 |
| T-L5-10 | 温度上升但未超 35 ℃（例 25→30 ℃）且 DARK | 不上报 | 只对下降（非超温）敏感，不用历史窗口统计 |

### 4.8 失败路径与有界性（联测 · 用例组 T-L6）

| 编号 | 行为 | 前置/资源 | 方法 | 证据 | 判定 |
|---|---|---|---|---|---|
| T-L6-01 | 测量失败不更新前值 | 钩子（优先）或行为反推 | ① 建立前值 30.0 ℃；② 注入一个周期的 I²C 故障（失败，不上报）；③ 恢复并把温度降到 28.8 ℃（相对 30.0 差 1.2 ℃ > 0.9 ℃）且 DARK，观察是否上报 | 波形 + 空中帧/钩子 | 恢复后必须上报（说明前值仍是故障前的 30.0 ℃，未被失败周期污染）。若实现改为「用失败周期值」，本项失败 |
| T-L6-02 | 失败周期不发 0 值帧 | 同上 | 检查故障周期内空中无帧，网关无 `temp=0` 记录 | 433 接收记录 + 网关日志 | 无帧、无 0 值记录 |

| T-L6-04 | 失败不阻塞下一拍 | 同上 | 失败后移除屏蔽，等待下一周期 | 波形 | 下一周期节拍不漂移、能重新上报 |

| 温度/湿度/照度参考 | 参考仪器读数 | 读数 + 时间 + 环境条件 |
| 判定 | 每用例：期望、实测、结论、证据路径 | 失败项需含最小复现步骤与现象时间点 |

证据与快照要求：每个结论必须能由保存的证据复现；不保存凭印象的结论。一次操作同时产生「手机侧结果 + 日志/波形」时需注明对应关系。

## 6. 前置条件、依赖与交接

8. **夹具与仪器**：逻辑分析仪、可调光源/暗箱、可控温度源、433 接收端或网关板、nA/µA 电流表；本次环境枚举仅确认了 `COM42`、Android 目标与 USB 摄像头在枚举层面在位。

## 7. 风险与限制

| 风险 | 影响 | 缓解 |
|---|---|---|
| 无内部观测钩子 | 光照 code、重试计数、前值是否更新只能间接观测 | 用 PB05/电流/空中帧 + 故障注入反推；接受证据强度下降并如实标注 |
| 光照阈值默认值未标定 | DARK 判定可能不符合实际安装场景（FWR-OPEN-4） | T-L3-03 标定并回填；标定值不得写成「已验收」 |
| RTC 基于 LSI，3 分钟为近似 | 长时漂移 | 长时基记录实际间隔与离散度；需求未给精度，不自造容差 |
| 单次 I²C 抓包受 SWD/调试影响 | 时序被调试器拖慢 | 时序类用例在**不挂调试器**、正常深睡运行下采集 |
| 433 发射与 I²C 共用 CPU | 发射期间时序争用 | 观察发射期间 PB05/PA03/PA04 无异常；电流无异常尖峰 |
| 温度激励不均匀（局部加热） | 误判下降/超温 | 用稳定温源并让传感器充分热平衡；记录参考仪器读数与等待时间 |
| 仅凭单一证据下结论 | 误判 | 每条 L3/L4 用例至少两类独立证据（见 §5） |

## 8. 准入与退出准则

**准入（开始执行的条件）**
- 传感器固件实现完成且 L0/L1 项可运行（`test/build_test.sh` 与 `gcc/build.sh` 存在并可用）；
- 传感器板已按新硬件焊装（GXHT40 + 光敏分压）并可上电；
- 逻辑分析仪、可控温度/光照源、433 接收端或网关板、电流测量仪器就绪；
- SWD 烧录/调试条件确认，`mdk_flash` 可用（否则涉及烧录的用例标为不可执行，不得伪造）。

**退出（本次测试设计交付的判定依据）**
- 适用用例的期望与实际一致 → 判定通过；
- 期望与实际不一致 → 记录为缺陷（含最小复现、证据、时间点）；
- 前置条件缺失（无设备/未授权/无观测手段/无协议定义）→ 对应用例返回 BLOCKED，不得记为通过；
- 需求未定义项（光照阈值数值、0.9 ℃ 含等于、深睡电流合格线、3 分钟精度、保活策略）→ 只记录实测与偏差，提交需求方确认，不自行判定合格。
