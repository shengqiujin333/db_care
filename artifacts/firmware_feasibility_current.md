## 5. 逐项结论：已证实 / 已否定 / 仍未知

### 5.1 已证实（本轮原始证据）

1. **光敏分压与 ADC 通道有真实响应**：光照增强时码值单调下降 `3750 → 3514 → 3061/3083`；`o=8/8`、极差 9/7 码、无满量程合成、无跳变。故 PB05 驱动、R3–J4 分压、PB04/AIN11 采样与固件取值链路**在工作**。
2. **S 行仍合规**：两条均为 78–79 B（≤96 B）、CRLF 完整、字段集合与顺序与 `debug_trace.c` 冻结格式一致、窗口内无杂散字节。
3. **节拍**：k=1002→1005 为 +3 分钟，与 180 s 采样节拍一致（本轮单窗口内两条连续周期）。
4. **未标定门禁生效**：`V=0`、`D=0`，即 `LIGHT_DARK_CALIBRATED=0` 时不会误判暗（这是门禁行为，不是判据通过）。
5. **判据可用性的算术边界**：判暗等价 `mean >= ceil(C_dark/3)`；`C_dark` ∈ 1..4095 → 判暗门限 ≤ 1365。直射实测 3061/3083 **高于**该上限 2.24 倍。

### 5.2 已否定（本轮证据直接排除）

1. **“直射条件下会出现低于判暗门限的低码”**——否定。预期（上一轮证据记录 `light_condition_20261110.md` §8 约定：“若 `a < 1365` 则存在可用低端分离”）与实际（3061/3083）不符。
2. **“1/3 判据在本硬件上可以通过标定实现”**——否定。穷举 `C_dark`=1..4095：暗态 3914–3932、首窗口 3750、房间灯 3514、直射 3061/3083 **全部 4095/4095 次被判为 dark，没有任何一个 `C_dark` 能让直射条件被判为“有光”**。要让直射判“有光”需 `C_dark > 3×3083 = 9249`，超出 12 bit。
3. **“完成完全遮光标定即可解决”**——否定。全遮光只会使 `C_dark` 落在 3750–4095，判暗门限随之升到 1250–1365，直射码 3061 仍远高于门限。故本轮**不再请求遮光窗口**（该实验对当前判据形式无判别力）。
4. **“房间灯条件下可判为有光”**——否定。房间灯 3514 同样需 `C_dark > 10542`。
5. **“判据未触发是因为缺一个常量”**——否定。缺的不是常量值，而是硬件响应幅度：实测亮/暗码比为 `3061/3914 = 0.782`（实测暗态最低均值 3914），判据要求 ≤ 0.333。

### 5.3 仍未知（影响责任归属，不影响“判据不可用”这一结论）

| 未知 | 为何仍未知 | 影响 |
|---|---|---|
| J4（GL4539）是否实际装配、焊点是否良好、受光面是否被外壳/被褥遮挡 | 无目视/影像入口，本能力不能看板；读数变化说明有光敏响应，但不能据此排除部分遮挡或接触不良 | 决定是“外部光照/机械”还是“器件/焊接”——责任方不同 |
| R3 实际阻值是否 5 M（BOM 标称） | 无万用表入口；只能由码值反推 | 若焊接值与 BOM 不符，绝对阻值会整体缩放，但**码值不变**，故不改变 §5.2 结论；只影响根因归属 |
| 用户“直射”的实际照度、距离、角度、是否对准器件 | 用户只回复“已直射”，未给参数；本能力无照度计 | 决定“最强可用条件”是否已用尽；若实际照度很低，§5.2 的结论是“在该照度下不可用”，需更强光源复测 |
| 直射时 `R_ldr≈14.8 MΩ`（=2.96×R3）是否符合 GL4539 在强光下的正常值 | 项目中无 GL4539 数据手册（仅 `gxht40.pdf`） | 需器件资料或硬件方判断；不作为固件结论 |

**不做的推断**：不把失败归因为“外部装配/设备问题”后排除；上述未知均有对应的最小判别实验（§6、§7）。

## 8. 对方案的影响（阻塞点，供下游决策）

1. **需求 4 的“无光”门当前不可实现**：以任何合法 `C_dark`，本板在暗、房间灯、直射三种条件下都被判为“无光”。若此时把 `LIGHT_DARK_CALIBRATED` 置 1（无论 `C_dark` 取多少），设备会在**有光环境**下按“无光 + 升温 >0.9 ℃”上报，与需求 4 的意图相反——这是必须避免的错误方向。本轮**未做**该修改。
2. **“升温分支”当前完全不会触发**（`CALIBRATED=0` → 升温条件恒伪），仅 `>35.0 ℃` 分支可用。这是设计阶段的有意门禁，不是缺陷；但它意味着交付物尚不能满足需求 4 的主路径。
3. **不受影响的已实现能力**（可继续沿用，不需重做）：GXHT40 采集/CRC/换算、UART1 调试输出与行预算、180 s 节拍、433 空口帧与网关兼容（静态/宿主证据）、>35.0 ℃ 严格边界判定、失败可诊断与有界等待。
4. **判据数值/形式属需求与硬件决策**：固件侧只能实现已批准的判据；本轮不修改 `LIGHT_DARK_REF_CODE`、`LIGHT_DARK_CALIBRATED` 或 `light_is_dark`。
5. **可行性判断**：关键功能（有光/无光区分）在真实目标上失败，且“判据形式与硬件幅度不匹配”已由穷举证据支持，而“照度是否已用尽”仍待 E1/E2。按能力规则返回 `WORK_FAILED`，阻止按探索成功进入设计；报告不作为整体产品失败的结论，跨链路/功耗/上电五行等未执行项不在本报告判定范围内。

边界说明：

- 数字/串口观测只证明 S 行字段所载的 ADC 原始码；不能证明模拟幅度、上升沿或实际照度。
- `R_ldr` 为**计算值**（由码值与 BOM 阻值比反推），不是器件实测。
- 本轮未读回 Flash，板上镜像身份按历史 `Verify OK` 记录引用；`git diff` 只证明源码未变。
- 单窗口（280 s、2 条 S 行）不足以外推长期稳定性；结论只依赖“码值远高于任何合法门限”这一与时间无关的量级关系。
- 本轮无后台任务、无遗留进程；串口已释放；未改变目标供电/接线/固件。
