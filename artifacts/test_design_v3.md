## 1. 能力边界与本轮声明

### 1.1 本能力做什么

- 设计测试范围、层次、环境、仪器、刺激、观测、判据、证据保存与交接。

- 明确哪些结论只能由宿主机证明、哪些必须由实板证明、哪些当前条件无法证明。

### 1.2 本能力不做什么

- **不执行**编译、烧录、复位、串口采集、逻辑分析仪采集、ADB 操作、网关/服务器访问。

- 不替实现能力修复缺陷，不替后续验证能力宣布通过，不替产品决定未决语义。
- 不把宿主机/mock/构建成功写成实板或产品通过。

### 1.3 本轮工具边界（实际调用事实）

本能力有效工具仅为：`Read`、`Glob`、`Grep`、`Bash`（受命令 gate 限制）、`Write`、`Edit`，以及只读设备枚举 `serial_list_ports`、`usb_list_devices`、`sigrok_info`。`serial_capture`、`mdk_build`、`mdk_flash`、`sigrok_capture/probe/decode`、`android_test` 在本能力**不可用**，属后续执行能力。

## 3. 观测方法与能力边界（防止结论外推）

| 方法 | 能证明 | **不能**证明 |
|---|---|---|
| `COM43` UART1 原始字节 | 固件上电确实初始化并输出；`BOOT→VDD→IOTEST→IOSIG→BUS` 顺序；每周期一行 `S`、失败追加 `G`；字段值、行长、周期结构；`S.p/H` 是否为判定前快照；`S.s` 最终本地发送结果 | I²C 位级电气/真实波形；`BUS ack=` 只证明地址级应答；`G raw` 只证明软件读回字节；绝对温湿度精度；空口到达 |
| `mdk_build/mdk_flash` 日志 | 当前提交可编译、可下载、回读校验通过、镜像可区分 | 任何业务功能；编译/下载成功 ≠ 功能通过 |
| 逻辑分析仪被动 `.sr` | 数字电平范围内的地址/命令/读事务顺序、ACK/NACK、SCL 位周期（样点分辨率内） | 模拟幅度、上升沿形状、焊点连通、器件是否得电、绝对时序余量；**错误通道映射会产生伪 ACK，必须判别后再用** |
| 网关 + 手机 | 同一次上报能走完 433→网关→BLE→手机；同笔读数一致 | 空口电气/丢包率；App 内部业务/报警/UI 判定（属软件测试） |
| 宿主机 harness（真实 `.c` + 影子 MCU/mock） | 纯逻辑与流程的确定性与精确边界：14 向量、恰好 +0.9 ℃、恰好 35.0 ℃、int32 边界、冻结帧逐字节、3 次用尽、判定前快照、UART 有界循环、UID 零路径、编译期标定门禁 | 真实目标行为；不得以 harness 通过冒充实板结论 |
| 完全遮光 | 全暗原始 ADC 样本与“读数越高越暗”的方向性 | 绝对照度；暗箱级重复性；阈值邻界精确扫描（归宿主机全量域） |
| 安全加温 | 真实升温/降温/超温的方向性触发 | 精确 `Δ=9`/`cur=350` 边界（归宿主机） |
| 可选仪器（§8.10 T-L8-04..06） | 电流、峰值压降、绝对精度、受控光源 | 本轮未执行；不得写成通过前提 |

**判定纪律**：每个实板/联测结论至少保留两类独立证据（如“`S` 行 + 手机读数”或“`S` 行 + `.sr`”）。单一 `BUS`/`G` 行不能定器件损坏；空抓包/超时是现象，不是功能通过或器件损坏的结论。

### 4.2 前置顺序

1. **L0/L0i/L1 可先行**：纯逻辑、流程、空口互操作、构建与静态不依赖 GXHT40 应答。
2. **L2 是其余实板观测的前置**：先证明当前镜像能启动、能打印、行长/字段自洽，再做 L3/L4/L5。
3. **L3 标定是升温分支的前置**：未标定 `V=0/D=0`，升温分支必然关闭；不得把“未标定”当“无光判定通过”。
4. **GXHT40 真实 ACK（U01）是任何 `q=1`、升温、超温、端到端的前置**：未闭合时相关实板用例只能是 `NOT EXECUTED / CONDITIONAL`，不得用宿主 mock 替代。
5. **冻结/失败/有界语义以 L0/L6 为主证据**，实板只观测可见部分；真实目标上不伪造发送失败。

### 8.4 L2 UART1 与诊断行（真实目标，主观测层）

**前置**：受测镜像已部署（T-L1-09/12）；`COM43` @9600 8N1；捕获窗口内可复位；逻辑分析仪可选旁证；捕获窗口建议 60–300 s 分区执行。

**解析约定（字段/顺序/键名冻结）**：

```text
BOOT   fw=<构建标识> uid=<8HEX> rst=<4HEX> uart=9600
VDD    ok=<0|1> code=<uint> bgrmv=<uint> mv=<uint>
IOTEST sda_lo=<0|1> scl_lo=<0|1> idle=<0..3> swap=<none|addr7[,addr7]> gc=<uint>
IOSIG  scl=<5HEX> sda=<5HEX>
BUS    idle=<0..3> scl=<0|1> sda=<0|1> ack=<none|addr7[,addr7...]>[+]
S      k=<uint32> p=<int> H=<0|1> V=<0|1> o=<0..8> n=<uint> x=<uint> a=<uint>
       D=<0|1> t=<int> h=<uint> q=<0|1> r=<0|1> s=<0|1|2> y=<uint>
G      s=<1..5> a44=<0|1> a45=<0|1> rd=<0..5> at=<uint> raw=<12HEX|------------>
```

| 编号 | 行为 | 前置/资源 | 方法 | 证据 | 判定 |
|---|---|---|---|---|---|
| T-L2-01 | 启动横幅 | 窗口内复位 | 先开捕获，再复位，解析首行 | 原始字节 + 时间窗 | 恰一条；含构建标识/UID/4 位 HEX `rst`/`uart=9600`；9600 无乱码；同一板多次复位 UID 一致；`rst` 随复位方式变化、非恒定 |
| T-L2-02 | 上电顺序与诊断行 | 同一窗口 | 解析 `BOOT→VDD→IOTEST→IOSIG→BUS`；确认在任何周期 `S` 之前、只出现一次 | 原始字节 | 顺序正确、各一条；`BUS` 后才有周期行 |
| T-L2-03 | 每周期一行 `S` | ≥2 个周期 | 分区窗口捕获；逐行解析 | 原始字节 + 窗口起止 | 每周期恰一条 `S`；15 字段齐全；无乱码/截断；无 `P` 行（本版无此字段） |
| T-L2-04 | 行长 ≤96 B | 同上 | 对 `BOOT/VDD/IOTEST/IOSIG/BUS/S/G` 按**线上原始字节**（含 CRLF）计数 | 逐行字节数 | 每行 ≤96 B；不得放宽 |
| T-L2-05 | `S` 字段自洽 | 同上 | 逐行：① 由 `V && 3*a>=C_dark` 重算 `D`；② 由 `H && int32(t)-int32(p)>9 && V && D` 或 `int32(t)>350` 重算 `r`；③ `o∈0..8`、`n<=a<=x`、`a==0 ⟺ o==0`、`t/h` 域、`s∈0/1/2`、`y==0` | 重算表 + 原文 | 全部一致；任一条不符即判“打印与内部判定不符” |
| T-L2-06 | **`p/H` 为判定前快照** | ≥3 周期 | 对相邻成功周期：本行 `t=Tn`，下一行 `p` 必须等于 `Tn`（不是下一行 `t`）；成功行允许 `p!=t`；失败行 `q=0` 且下一成功行 `p` 仍为失败前值 | 逐行状态表 | 与 FWR-306/309 一致；若仍见 `p==t` 且无法由历史解释，登记 D-02 未修 |
| T-L2-07 | 采样间期静默 | 跨采样间隔 | 统计 `S/G` 后到下一周期前的字节 | 分段字节数 | 间期 0 字节（UART 已关闭） |
| T-L2-08 | 关闭不破坏软 I²C | ≥2 周期 | 第 2 周期起仍有有效光照/温湿度尝试 | `S` 序列 | 首次关闭后后续周期正常；否则登记关闭副作用 |
| T-L2-09 | 关闭不破坏 SWD | `mdk_flash` 可用 | 成功打印一次后再次下载校验 | 第二次日志 | 再次 `Verify OK`；失败登记调试通道副作用 |
| T-L2-10 | **`S` 在发送结束后打印** | 出现触发周期 | 触发一次上报；确认该周期 `S.s` 为该周期最终结果（1 或 2），而不是第一次尝试的中间值；同周期只一条 `S` | `S` 原文 + 发送记录（手机/仪器） | `s` 与最终结果一致；无“第一轮失败就打印 `s=2` 后又继续重试”的现象 |
| T-L2-11 | `BUS` 与 `G` 自洽 | 上电 + 失败周期 | `BUS idle` 与 `scl/sda` 位一致；`ack` 为合法 7bit 地址或 `none`，≤8 个，`+` 表示截断；与失败周期 `G a44/a45` 不矛盾 | 两行原文 | 自洽；`BUS` 只证明地址级应答 |
| T-L2-12 | **`G` 仅在失败周期且可复算** | 出现 `q=0` | 确认 `S` 后紧跟一条 `G`；用独立 CRC-8 对 `raw` 两段复算；核对 `s/a44/a45/rd/at` 组合与失败形态不矛盾；`q=1` 周期无 `G` | 逐行原文 + 复算表 | 条件/取值/计数自洽；成功周期无 `G` |
| T-L2-13 | 上电诊断自洽 | 上电窗口 | `IOTEST.sda_lo/scl_lo`（0=拉低成功）、`idle`、`swap`；`IOSIG` 20 bit 与地址 `0x88` 位序列一致（无器件时 `scl=95555/sda=30303`）；`VDD ok=1` 时 `mv≈4095*bgrmv/code` | 行原文 + 计算 | 字段自洽；`ok=0` 不解释为电压 |
| T-L2-14 | **`q=1` 真实采集（OBS-1/U01 闭环）** | 连续 ≥3 周期 | 逐步解析 `S`：`q=1`、`t∈−400..1250`、`h∈0..1000`，与现场环境相符；观察稳定性 | 连续原文 + 环境记录 | 连续多周期有效且不发散 → 通过；仍 `q=0` 时以 `BUS/G` 数据定位并交实现/硬件，**不得**以“已诊断”代替“已恢复” |
| T-L2-15 | 正常行无截断 | 正常 UART | 检查每条行尾 CRLF 完整、无半个字符 | 原始字节 | 正常路径不得出现截断；截断只在故障注入时允许 |
| T-L2-16 | 横幅标识与受测件一致 | 部署记录 | `BOOT fw=` 与 `SENSOR_FW_BUILD_ID`、commit、axf md5 对应 | 原文 + 清单 | 四者一致；不得用历史横幅 |

### 8.7 L5 条件上报与端到端（真实目标/联测，核心）

**激励**：局部安全加温（手心/腋下/被窝/暖水袋隔布；禁止明火或直接接触热源）；遮光；可持续 >35 ℃ 的方式。

| T-L5-01 | 有前值；遮光；升温 ≥1.0 ℃ | 上报 | 该周期 `r=1`、`s=1`；同周期一条 `S`；手机同一时段收到该笔且温度一致 |
| T-L5-02 | 有前值；有光；同样升温 | 不上报 | `r=0`；无发送；手机无新读数（记录窗口） |
| T-L5-03 | 有前值；光照无效/未标定；升温 | 不上报（升温分支关闭） | `r=0`、`V=0`；无发送 |
| T-L5-04 | 有前值；遮光；降温 ≥1.0 ℃ | 不上报 | 方向为升温；降温恒不触发（as-built D-01 未修时本项会失败，属合法失败） |
| T-L5-05 | 有前值；遮光；升温但 <1.0 ℃ | 不上报 | 以 x10 整数差为准；差值 ≤9 不得上报 |
| T-L5-06 | 无前值（复位首笔）；≤35.0 ℃ | 不上报 | 首笔 `H=0`、`r=0`；无发送 |
| T-L5-07 | >35.0 ℃；有光 | 上报 | 超温分支独立于光照/前值；`r=1` 且手机收到 |
| T-L5-08 | >35.0 ℃；遮光/光照无效 | 上报 | 与 T-L5-07 结论一致 |
| T-L5-09 | 上报成功后同条件持续（无新升温） | 不重复上报 | ≥2 周期无新触发；成功后清除；无跨周期补报 |
| T-L5-10 | 有前值；遮光；多周期稳定 | 不上报 | 无周期保活/心跳；`t/h` 仍逐周期有效 |
| T-L5-11 | 触发周期的帧内容 | 帧=触发样本 | 手机读数与该周期 `S.t/h` 一致（同一笔，非相邻周期） |
| T-L5-12 | `s` 与触发自洽 | 无伪造 | `r=1` 时 `s∈{1,2}`；`r=0` 且无待发时 `s=0`；`s=2` 须与真实链路条件对应并记录 |
| T-L5-13 | 失败周期不推进前值 | 无推进/无发送 | 该周期 `q=0`、无发送；下一成功周期 `p` 仍为失败前值 |
| T-L5-14 | 失败后升温 | 以失败前 prev 判定 | 恢复后 `p` 等于失败前有效样本；升温差按该值计算 |
| T-L5-15 | **单周期最多 3 次** | 最终结果 | 实板正常路径不应伪造失败；若出现 `s=2`，同周期只一条 `S` 且 `y=0`；尝试次数由宿主 T-L0-12/T-L6-07 证明，**不得**要求 `S` 行可见次数 |
| T-L5-16 | 下一周期重新判定 | 不跨周期积压 | 用尽后下一周期按新采样自然判定；无强制补报、无旧帧重发 |

> 所有内部判定用例必须与至少一次真实手机收到的读数一致；不一致时以端到端结果为准并登记缺陷，不擅自改网关/App。

### 8.8 L6 冻结、失败路径、有界性与诊断复算

| 编号 | 行为 | 前置/资源 | 方法 | 证据 | 判定 |
|---|---|---|---|---|---|
| T-L6-01 | 冻结帧逐字节一致 | 宿主 `measure.c` + 发送桩 | 见 T-L0-12/13；在 3 次尝试中改变外部新采样值 | 每次帧 hex | 所有尝试帧相同且等于触发样本 |
| T-L6-02 | 用尽放弃不伪造 | 同上 | 3 次失败 → 状态清零；后续周期可重新判定 | stdout + 状态 | 不返回成功；不无限重试；不跨周期 |
| T-L6-03 | 仅成功/用尽清除 | 同上 | 失败 N 次后成功 1 次；或直接用尽 | stdout | 成功清除；用尽也清除；无残留 |
| T-L6-04 | 无待发不发送 | 同上 | `report_req=0` 调用发送 | 调用计数 | 发送桩 0 次；不组帧 |
| T-L6-05 | 实板可见冻结 | 传感器 + 网关 + 手机 | 不伪造失败；核对触发周期 `S.s` 与手机读数一致 | `S` + 手机 | 端到端一致；逐字节不变性由 T-L0-12/13 负责 |
| T-L6-06 | 失败不构造 0 | 宿主 | 失败周期后检查无 0 值帧/无 0 样本进入发送 | 帧 dump | 无 0 值帧 |
| T-L6-07 | **尝试次数证据** | 发送桩调用计数 | 成功在第 1/2/3 次、失败 3 次分别计数 | 调用日志 | 次数与脚本完全一致；`S.y` 不承担该语义 |
| T-L6-08 | `G` 行事实复算 | 独立 CRC-8 + mock 总线 | 对实板 `raw` 复算；位级 mock 构造“无器件/读 NACK 用尽/CRC 错/量程无效”，核对快照 | 复算表 + mock 表 | 与构造一致；只读 |
| T-L6-09 | 失败后重探与有界恢复 | 位级 mock 总线 | 读失败 → 下一周期重探两地址；SDA 卡死 → 9 个 SCL 脉冲 + STOP、有上限；恢复后重探；无 `0x94`/加热命令 | 线上字节 + 计数 | 每次失败后重探；有界；无永久失联 |
| T-L6-10 | **UART 卡死隔离** | 影子 UART + 实板可见部分 | 主机：TXE/TXBUSY 永不就绪 → 有界中止、仍关闭、业务状态不变；实板：正常路径无截断、间期静默 | 影子计数 + `S` 序列 | 故障不阻塞采样/判定/发送/睡眠；实板卡死无法在不变硬件下构造时如实记“主机证明+静态预算” |

### 8.9 L7 跨链路一致性（只读，不改网关）

| 编号 | 行为 | 前置/资源 | 方法 | 证据 | 判定 |
|---|---|---|---|---|---|
| T-L7-01 | 网关解析/记录顺序 | 网关源码只读 | `decode_frame10` 取 `temp=p[4..5]`、`hum=p[6..7]`；`app_um2006A.c` 写 `id|hum_be|temp_be`；`bleencrypt.c` 与手机解析一致 | 文件+函数引用 | 三方一致；无需改网关 |
| T-L7-02 | 同笔端到端 | 传感器+网关+手机 | 触发一次上报；比对 `S.t/h` 与手机同笔读数/时间窗 | `S` + 截图/日志 | 温度/湿度/符号一致；不互换 |
| T-L7-03 | 帧布局未变 | 源码 + T-L0i | 10 B 明文/CRC16/Feistel 未变；无光照/原因/时间字段上链 | diff + 往返 | 布局不变 |
| T-L7-04 | 网关不二次门控 | 源码 + 在链 | 网关只解密/校验/缓存/聚合；传感器 `s=1` 后手机应收到 | 源码 + 手机 | 收到即转发；未收到则登记跨链路问题 |
| T-L7-05 | ID 归因稳定 | 复位前后 | 横幅 UID 前 4 B 与空口 ID、手机归因一致 | 原文 | 稳定一致 |
| T-L7-06 | 手机不合成数据 | 稳态 ≥3 周期 | 无触发时手机是否出现伪造/0 值 | 手机记录 | 不把未收到当 0；App 语义属软件测试 |

### 8.10 L8 仪器旁证与可选扩展

| 编号 | 项目 | 资源 | 方法 | 当前状态/判定 |
|---|---|---|---|---|
| T-L8-01 | **逻辑分析仪通道身份判别** | `fx2lafw:conn=2.35`（已登记/已枚举） | 先抓一段已知事务（上电 `BUS` 扫描或周期测量）；分别按 `D0=SCL/D1=SDA` 与 `D1=SCL/D0=SDA` 离线解码；正确映射必须重现固件已知的 `0x88/0x8A` 地址序列及 ACK/NACK 行为；记录实际夹线 | **执行前必做**；配置标签与实际不一致时，错误映射的伪结果（如伪 `0x10` ACK）不得作为证据；只提配置补全建议，不改配置 |

| T-L8-03 | SCL 位周期与时序余量 | 逻辑分析仪 | 由样点/采样率计算位周期；记录采样率/样点数/通道映射/触发条件 | 旁证；数字采样不证明模拟幅度/上升沿 |
| T-L8-04 | 深睡/发射电流与 CR2032 峰值压降 | 电流表/示波器 | 未登记 | **可选扩展，未执行**；不作为通过前提 |
| T-L8-05 | 绝对温湿度精度与受控光源/暗箱 | 参考仪/温源/暗箱 | 未登记 | **可选扩展，未执行**；本计划只证明内部一致与方向性 |
| T-L8-06 | PB05 供电窗口/PB04 建立时间波形 | 示波器 | 未登记 | **可选扩展，未执行** |

**逻辑分析仪使用纪律**（来自 FEX-001 与环境约束）：
1. 采集前确认输入电平范围、共地、实际通道连接；只使用项目确认的 `conn=2.35`，不做全局扫描、不写 EEPROM。
2. `sigrok_probe/capture` 会访问目标并可能加载 RAM 固件、改变 USB 地址；不能描述为纯配置查询。
3. 先保存原始 `.sr` 与完整日志/采样元数据，再离线解码；空抓包/超时/无数据只记现象。
4. `D1=f` 触发在实测映射下可能是 SCL 下降沿，不是限定 SCL 高电平的 START；不得据此断言协议。
5. 数字采样只证明逻辑电平与样点分辨率内时序，不证明模拟幅度、焊点连通或器件得电。

1. 版本绑定：提交、axf md5、板号、镜像标识、时间。

4. 旧证据排除：旧提交/旧镜像/COM42/旧运行结论不得复用。
5. 层级标注：宿主/mock 结论必须显式标注，不得写成实板结论。
6. 不推断：代码/单测/下载成功不能推出真实条件通过。

## 11. 风险与限制

| 风险 | 影响 | 缓解 |
|---|---|---|
| U01 未闭合（`q=0`） | 温湿度/升温/超温/端到端实板用例全部不可执行 | 先做 L0/L1；实板以 `BUS/G` 定位；`q=0` 时不得宣称其它依赖温湿度的结论通过 |
| 实现未按 FDS-003 修正 | 大量用例合法失败 | 执行前核对 D-01..D-11；失败即证据，交实现能力，不下调期望 |

| UART 有界无法在实板构造 | 缺少真实卡死证据 | 主机有界循环 + 静态预算 + 实板正常行时；如实说明局限 |

| 分区窗口分辨率限制 | 节拍精度受限 | 10–30 s 窗口 + `k` 增量；记录离散度，不自造容差 |

| 旧镜像/旧日志冒充 | 验证错对象 | T-L1-12 四者一致 |
| 单一证据下结论 | 误判 | 每结论至少两类独立证据 |
