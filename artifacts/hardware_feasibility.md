# 硬件可行性评估报告（HFE-001）

状态：硬件方案设计产物
版本：1.0
对象：蹬被报警器传感器增量（霍尔检测 + 光敏接收手机闪光灯参数）
关联：artifacts/hardware_solution.md（HW-001）

## 1. 结论

**可行（FEASIBLE）**。在现有传感器原理图基础上增量增加 F1 霍尔检测、F2 光敏接收（可关断）功能块，技术上成熟、成本低、对现有设计侵入小，符合 IC-001 §8 对硬件的三项要求（Hall 数字输入、可关断光敏前端电源、可定时采样数字输入）。

## 2. 可行性依据

| 维度 | 评估 | 说明 |
|---|---|---|
| 器件成熟度 | 高 | 霍尔开关、光敏三极管、小信号 MOSFET 均为成熟低成本器件 |
| 信号带宽 | 充分 | IC-001 为 40 ms/bit Manchester（25 Hz），光敏三极管 + 电阻完全覆盖，无需运放/ADC |
| MCU 资源 | 充分 | CW32L010 有 ≥3 个空闲脚（PA2/PB4/PB5/PB6），可同时满足 Hall 中断输入 + 光敏采样输入 + 电源开关输出，无需换 MCU |
| 电源 | 可行 | CR2032 3V 直接供全部；F2 前端平时断电（暗电流≈0），30 s 窗口持续电流压到 <2 mA 满足 CR2032 持续电流限制；433 短脉冲为现状 |
| 对现有设计侵入 | 低 | 不改 AHT10/UM2005C/晶振/供电/433 天线；仅新增两个外围块 |
| 结构/光学 | 需注意 | F1 磁铁位与 F2 受光面朝向依赖外壳；暗夜使用条件明确（readme 指定） |

## 3. 关键风险与缓解

| 风险 | 影响 | 缓解 |
|---|---|---|
| 光敏前端持续电流超 CR2032 | 电池寿命下降 | F2 负载电阻按 <2 mA 选值；30 s 窗口短时存在 |
| Hall 静态电流拖累待机 | 常态暗电流超预算 | 器件选 µA 级；若 >5 µA 则 GPIO 关断 Hall |
| 光敏受光方向/灵敏度 | 配置成功率 | 暗夜 + 手机闪光灯为强光源，余量充足；schematic 阶段选高灵敏度光敏管 |
| 433 发射与 F2 大电流叠加 | 瞬时尖峰 | 固件调度避免叠加；CR2032 支持短脉冲 |
| 引脚适配（外部中断脚） | 需调整 | 空闲脚组内调整，不锁定单一硬编码 |

## 4. 需在后续阶段复核的数据（非阻塞）
