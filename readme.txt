这是一个蹬被报警器的项目，项目分为传感器、中继器、安卓手机app、苹果手机app几个设计。传感器采集被窝温度和湿度，通过温度和湿度的变化来判断有没有蹬被子。蹬被子后通过中继器进行传递给手机app。传感器和中继器通过433mhz无线信号传递数据，中继和手机之间通过蓝牙传递信号。供电是cr2032纽扣电池，焊接到电路板上。本次修改点：1、将温度传感器修改为GXHT40，说明书已经放到了本目录；2、增加了光敏电阻和电阻分压电路，具体可以看网表文件和bom文件；3、采集时间改为3分钟；4、上传的规则改为，当本次采集到的温度数据比上次采集的温度数据大于0.9℃，同时没有光的情况下，才上传数据；或者如果温度超过了35度也上传温度数据。5、平台broker相关的服务器信息已经放到了项目文件夹内；6、同步修改安卓的app，暂时不需要更改ios的app。同时，如果sensor的代码中有光通讯和霍尔识别相关的功能需要取消，这个功能不再使用了，不需要你修改硬件内容。7、当前的情况是有光的。你可以把没有光的阈值改为完全没有光的时候的1/3。8、本项目传感器使用uart1来作为调试串口，程序上需要能使用串口1进行调试，需要做初始化和打印什么的。补充条件与测试安排：
