这是一个蹬被报警器的项目，项目分为传感器、中继器、安卓手机app、苹果手机app几个设计。传感器采集被窝温度和湿度，通过温度和湿度的变化来判断有没有蹬被子。蹬被子后通过中继器进行传递给手机app。传感器和中继器通过433mhz无线信号传递数据，中继和手机之间通过蓝牙传递信号。手机可以设置参数给传感器，通过后置的闪光灯。而传感器这里通过磁性的霍尔开关来识别是否要有数据要传递，平时的时候光敏三极管不工作，来省电。供电是cr2032纽扣电池，焊接到电路板上

项目地址在：D:\mypro\beiwo2\AIP，里面有一个readme.txt，说明这是一个什么产品，项目里面包含中继和传感器的pcb电路板xml文件，包含他们的嵌入式代码，包含安卓手机程序。我需要给这个传感器增加一个功能：增加一个霍尔传感器检测磁铁，一旦发现磁铁，立刻用gpio给一个光敏二极管供电，然后光敏二极管来接收手机闪光灯发送的数据（黑暗夜里），数据包含6个float类型数据，一个是温度下降值，一个湿度下降值，一个温度低阈值，一个湿度低阈值，一个温度高阈值，一个湿度高阈值。一旦传感器发现超过这些阈值，立刻通过无线发送数据给网关，如果没有超过，则一个小时发一次数据给网关。同时改成1分钟测量一次温湿度，上面的阈值需要存储大约20分钟的数据buf，看ram情况。同时安卓这端也需要更改功能，增加闪光灯设置上面参数这些功能。
