## 5. 按分压电路反推的光敏阻值（计算值，不是器件实测）

拓扑（`sensor_hardware/pstxnet.dat` / `MAIN_BOARD.BOM`）：
PB05（`LIGTHT_POWER`）—R3 5 MΩ—PB04（`LIGHT_ADC`/AIN11）—J4（GL4539 光敏）—GND。

`R_ldr = 5 MΩ × code / (4095 - code)`

| `a` | 反推 `R_ldr` | 场景 |
|---|---|---|
| 3514 | ≈ 30.2 MΩ | 本轮“房间灯”条件 |

### 10.4 判据可用性的穷举结论（算术，不是实测）

- 现行规则：`dark = valid && (3*mean >= C_dark)`，等价于 `mean >= ceil(C_dark/3)`。
- 12 bit ADC 使 `C_dark` 只能取 1..4095，故判暗门限最高为 `ceil(4095/3)=1365`。
- 本轮直射实测 `a=3061/3083`，历史暗态 3914–3932、房间灯 3514：**对每一个合法 `C_dark`，这些条件全部被判为 dark，无一可被判为“有光”**（穷举脚本 `analyze_light_gate.py`，输出 `light_gate_analysis_20261110.txt`）。
- 要让直射条件被判为“有光”，需要 `C_dark > 3×3083 = 9249`，超出 12 bit 表示范围 → 不是标定问题，是规则与该硬件响应幅度不匹配。
- 结论：即使用户再完成“完全遮光”标定，`C_dark` 只会落在 3750–4095 区间，判暗门限随之升到 1250–1365，直射码 3061 仍远高于门限。**全遮光标定无法挽救该判据**，因此本轮不再请求遮光窗口。

证据正文见 `artifacts/firmware_feasibility_current.md`（FW-EXP-003）。
