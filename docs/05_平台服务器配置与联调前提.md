| `dengbei_care/app/src/main/java/com/jinyuni/dengbei_care/MqtttService.kt` | `TLSv1.2`、`jd-ca.crt` 加载、`clientId="android_client"`、topic `/<mac>/a/r0`（订阅）、`/<mac>/a/s0`（发布） | 兼容面，改动需协议评审 |
| `dengbei_care/app/src/main/res/xml/network_security_config.xml` | 明文放行入口共 3 个 `domain-config`：`8.140.23.253`（平台）、`117.72.84.210`（旧主机历史条目，非连接目标）、`192.168.4.1`（网关本地配网热点） | 不得新增其它主机、不得全局放开明文；独立静态核查要求域名集合精确为这 3 个 |
| `POST /upload_data` 请求体 | `{"phone":"…","mac":"<网关MAC>","readings":[{"devId":"A1B2C3D4","time":<unix 秒>,"temperature":25.5,"humidity":60.0}]}` | 温度 ℃、湿度 %RH、时间 Unix 秒；字段名/结构不得随意变更 |

MQTT 认证约定：用户名 = 设备 MAC（12 位十六进制大写），密码 = 用户名 + 项目资料约定的固定后缀。**固定后缀属共享凭据，本文档不复制**；轮换需同时更新服务端认证库与客户端规则，并在受控记录中留痕。

## 5. 联调前置清单（进入联调阶段前必须满足）

| # | 前置 | 说明/责任 |
|---|---|---|
| D1 | `/upload_data` 受理条件定性 | 需平台侧以**隔离测试身份**在明确写授权下执行一次真实 POST，记录请求头/体/响应与结果 |
| D2 | 测试身份与设备 | 独立测试手机号 + 测试网关 MAC；不得使用真实用户数据 |
| D3 | 写授权 | 明确 `POST` 调用、必要时的清理动作；本轮无此授权 |
| D4 | 持久化与幂等验证方法 | 服务端 `sensor_data` 的 `(dev_id, time)` 唯一键需实际验证重复上传不增行；本轮未读表、未连库 |
| D5 | 回读方法 | 不直连数据库时的回读途径（接口或授权查询），需与平台方约定 |
| D6 | 网关在线与绑定 | 网关供电、蓝牙可发现、App 绑定 ≤9 台；网关固件本轮未修改 |
| D7 | 观测时间窗 | 3 分钟采样 + 条件上报，验证窗口需覆盖 ≥2 个上报机会 |
| D8 | 固件判据状态 | 交付固件 `T=0`，"升温+无光"分支不触发；联调触发数据只能来自 >35.0 ℃ 分支或既有缓存 |

未满足 D1–D5 时，"云端上传成功"只能写"HTTP 受理（未验证持久化）"。

## 6. 服务器变更步骤（需授权，本轮不执行）

1. 取得变更授权与维护窗口；确认可回退（备份 `abr.py`、EMQX 配置、数据库快照）。
2. 仅修改必要项（主机地址/证书/端口），保持 6 个路由、请求体字段与 `sensor_data` 结构不变。
3. 客户端只改 `CloudConfig.kt` 一处；重新构建并核对 APK 身份。
4. 变更后按 §5 清单逐项验证，并记录证据（时间、命令、响应、脱敏后的日志）。
5. 失败时回退到变更前配置，不保留半迁移状态。

**禁止**：重装系统、清空数据、改防火墙开放面、直连生产库做试验、使用真实用户凭据测试、在客户端硬编码新的鉴权方式。

## 7. 排障

| 现象 | 可能原因 | 排查 |
|---|---|---|
| App 无法连接 MQTT | 证书/端口/网络/凭据 | 核对 `ssl://8.140.23.253:8883`、`jd-ca.crt` 未被替换、手机网络可达；不要用 `--insecure` 结论替代 App 行为 |
| MQTT 连上但无数据 | 网关未在线/MAC 不匹配/topic 不符 | 核对订阅 topic `/<mac>/a/r0` 与网关实际 MAC；确认网关 433 侧有数据 |
| App 上传一直 401/403 | 平台鉴权/受理条件（未定性） | 保留客户端状态与待发条数；交平台侧按 D1 定性；不在客户端加临时头 |
| 上传 4xx（非 401/403） | 请求体/字段/时间格式 | 核对 §2 请求体结构、单位与时间；保留原始响应 |
| 上传成功但查不到数据 | 2xx 仅表示受理 | 按 D4/D5 验证持久化与回读 |
| 服务不可达 | 主机/端口/服务状态 | 只读检查服务状态与端口；无变更授权时只报告，不重启 |
| 数据重复 | 网关缓存复读/重试 | 服务端唯一键与 App 待发箱幂等；同值不同秒属既有语义 |

## 8. 限制

1. 本轮**没有**服务端源码、部署脚本或数据库直连授权；`abr.py` 内容未读取，401 机制未知。
2. 服务端"复用"结论仅覆盖运行版本、端口、路由存在性与部署对象未变。
3. MQTT 认证使用共享固定后缀口令，存在横向风险；轮换属平台侧变更，不在本轮范围。
4. 光照数据不上传，服务端无光照列；不得据云端数据反推"无光"。
5. 3 分钟条件上报使云端序列稀疏，任何"连续曲线"都不是原始采样序列。
