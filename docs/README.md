## 3. 全局安全与范围约束（来自当前需求与授权汇总）

1. **不得修改或烧录既有网关（CH592 `beiwov2`）**；跨链路只在后续联调阶段执行。
2. **不安排调温、改变光强、遮光刺激和功耗测量**的测试；当前现场"有光"是既定条件。
3. 传感器供电为**焊接在板上的 CR2032**，不可拆换；断电/复位只能通过调试器复位或整板断电。
4. 平台服务器**只复用、不重部署**；数据库直连与写接口无本轮授权。
5. 文档与日志中**不得出现口令、密钥、手机号等凭据明文**；本包只引用配置变量/文件位置。
6. 文档不代替独立验证；未执行项必须随交付披露（见 06 文档 §4）。

## 4. 版本与来源引用规则

- 固件身份以**源码提交 + 产物摘要**为准，不以 `BOOT fw=FD-002r4` 横幅为准（该横幅是字节冻结的字符串，不代表版本号）。
- APK 身份以**包名/versionCode/versionName + 签名 + SHA-256** 为准；同一源码两次构建的字节摘要可能不同。
- 平台服务身份以**部署对象元数据 + 运行版本**为准（`/root/abr.py` 8949 B、mtime 2026-10-22、EMQX 5.8.0）。
- 引用证据时给出仓库内相对路径，便于复核（见各文档末尾"依据"小节）。
