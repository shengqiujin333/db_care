## 4. 版本与来源引用规则

- 固件身份以**源码提交 + 产物摘要**为准，不以 `BOOT fw=FD-002r4` 横幅为准（该横幅是字节冻结的字符串，不代表版本号）。
- APK 身份以**包名/versionCode/versionName + 签名 + SHA-256** 为准；同一源码两次构建的字节摘要可能不同。
- 平台服务身份以**部署对象元数据 + 运行版本**为准（`/root/abr.py` 8949 B、mtime 2026-10-22、EMQX 5.8.0）。
- 引用证据时给出仓库内相对路径，便于复核（见各文档末尾"依据"小节）。
